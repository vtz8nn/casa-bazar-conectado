DESIGN RESPONSIVO

O site deve funcionar perfeitamente em:

- Celular
- Tablet
- Notebook
- Desktop
- Monitores grandes

Priorizar a experiência mobile.

No celular:

- Menu hambúrguer
- Botões grandes e fáceis de tocar
- WhatsApp flutuante
- Cards adaptáveis
- Imagens otimizadas
- Texto perfeitamente legível
- Navegação rápida

ANIMAÇÕES

Adicionar animações elegantes e discretas:

- Fade-in ao entrar nas seções
- Cards aparecendo suavemente
- Hover nos botões
- Pequenas transições
- Animação suave no botão do WhatsApp

Não exagerar nas animações.

O site deve parecer profissional, não uma página cheia de efeitos.

SEO

O site deve ser otimizado para pesquisas locais.

Título da página:

Guilherme Bazar e Papelaria | Bazar, Papelaria e Utilidades em Nova Iguaçu

Descrição:

Guilherme Bazar e Papelaria em Nova Iguaçu - RJ. Encontre papelaria, utilidades, decoração, presentes e muito mais. Entre em contato pelo WhatsApp.

Utilizar palavras-chave relacionadas a:

- Bazar em Nova Iguaçu
- Papelaria em Nova Iguaçu
- Utilidades em Nova Iguaçu
- Decoração em Nova Iguaçu
- Papelaria Belterra
- Bazar Belterra
- Guilherme Bazar e Papelaria

Implementar estrutura adequada de headings, textos alternativos nas imagens, URLs amigáveis e dados estruturados de negócio local quando possível.

PERFORMANCE

O site deve carregar rapidamente.

Otimizar:

- Imagens
- Código
- Fontes
- CSS
- JavaScript

Evitar elementos desnecessários que deixem o site lento.

ADMINISTRAÇÃO

Se a plataforma permitir, criar uma área administrativa simples para o proprietário alterar:

- Produtos
- Fotos
- Preços
- Descrições
- Categorias
- Horários
- Promoções
- Informações de contato
- Redes sociais
- Banners

O proprietário deve conseguir atualizar o conteúdo sem precisar programar.

EXPERIÊNCIA FINAL

O resultado deve parecer o site oficial de uma empresa real e profissional.

A estética deve ser:

Creme + marrom + elegante + moderno + acolhedor + sofisticado.

Não criar um site genérico.

Priorizar:
beleza + confiança + facilidade de navegação + conversão para WhatsApp + presença local.

O principal objetivo do site é fazer o visitante conhecer a loja, encontrar produtos/categorias e entrar rapidamente em contato pelo WhatsApp.

Antes de finalizar, verifique se:

1. Todos os botões funcionam.
2. O WhatsApp está configurado corretamente.
3. O endereço está correto.
4. O site funciona perfeitamente no celular.
5. Nenhuma informação foi inventada.
6. O visual mantém a identidade creme e marrom.
7. O site possui aparência profissional.
8. As imagens possuem boa qualidade.
9. O carregamento está otimizado.
10. A navegação é simples e intuitiva.
